PHOTON PRETZEL 0.4.0 — WINDOWS x64

1. Extract the entire Photon-Pretzel-0.4.0-win-x64.zip into a new folder.
2. Double-click Play.cmd (or OpticalPlayer.exe).
3. The included image opens and computes automatically. Left: stored sensor
   samples. Right: the computed optical reconstruction.
4. Apply gain changes the program INSIDE the image; 0.5 halves the complex
   field and quarters its displayed intensity. Run image executes it again.
5. Save TIFF + GIF creates a new folder, checks both exports, and preserves
   the interpreter runtime, program and samples. Open image resumes either.
6. Reset demo reopens the initial image. After 24 instructions, reopen the
   initial demo to make more edits.

No Python, .NET installation, build command, internet or administrator access
is required to use this package. Keep all extracted files together.
The GitHub Source code ZIP is developer source and is not this Windows app.

The image carries an approved .NET interpreter module and its program/data.
The included reader loads the module from pixels, and your CPU executes it.
An ordinary image viewer only displays the image. This is a bounded numerical
simulation, not physical holographic hardware or free computation by pixels.

If Windows or organizational policy blocks the unsigned application, stop
and follow your administrator's approved process. Do not disable protections.
